# FlightCore

Installateurs de FlightCore, compagnon de bureau pour Star Citizen (Windows).

Première installation : `FlightCore_<version>_x64-setup.exe` de la dernière release. Les mises à jour se font ensuite depuis FlightCore (Paramètres › Mises à jour).

Ce dépôt ne contient que les installateurs ; le code source n'est pas publié. Composants tiers et leurs sources : dossier `piper\LICENCES` de l'installation.
